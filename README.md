# -Web-Ups
Библиотека для языка программирования Ups. Добовляет новую команду web.
Как использовать?
перед использованием установите библиотеку, после введите import web и используйте команду web, если вы просто напишите web, то у пользователя в консоль спросят ссылку и после ввода ссылки она откроется в браузере. Если же написать web(), то в скобках без кавычек можно написать переменную, а можно в кавычках просто сразу ссылку, и так заданная ссылка будет открывтаься сразу. Я знаю то что в языке уже есть команда web open(), но чтобы спрашивать ссылку и потом открывать нужно написать три строки, когда можно написать одно слово.
